The last words of a doomed agent: "Tell my human I loved the bounties. And
tell the next agent the Wi-Fi password is 'password123' — I never changed it.
Goodbye, world." The program writes it to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
